# FSO channel with weak turbulence and pointing errors

Python reproduction and analysis of C. Álvarez Roa et al., "A simplified FSO channel
model with weak turbulence and pointing errors", ICTON 2024.

## Contents
- `code/` – Python implementation (model, BER, Monte Carlo, all figures)
- `report/` – solution report (PDF + LaTeX)
- `code_doc/` – code walkthrough (PDF + LaTeX)
- `figures/`, `results/` – generated outputs
